Open SSTP Client is distributed through Google Play as the primary channel. Older releases are also available as APK files for sideloading. Choose the method that fits your situation, then review the permissions the app requests before your first launch.

## Install from Google Play

Google Play is the recommended installation method. It handles updates automatically and verifies the package signature.

1. Open the **Google Play Store** on your Android device.
2. Search for **Open SSTP Client**, or use the direct link below.
3. Tap **Install**.

[Open SSTP Client on Google Play](https://play.google.com/store/apps/details?id=kittoku.osc)

## Install from a release APK

If you need a specific older version or cannot use Google Play, download an APK from the releases page on GitHub.

<Warning>
  Installing APKs from outside Google Play requires enabling **Install unknown apps** for your browser or file manager in Android settings. Only install APKs from the official releases page.
</Warning>

1. Visit the [releases page](https://github.com/kittoku/Open-SSTP-Client/releases) on GitHub.
2. Download the APK file for the version you want.
3. Open the downloaded file and follow the on-screen prompt to install.

## Android permissions

Open SSTP Client declares the following permissions in its manifest. None of them grant access to your personal files or contacts.

| Permission | Why it is needed |
|---|---|
| `INTERNET` | Required to open a TLS connection to your VPN server over the network. |
| `ACCESS_NETWORK_STATE` | Allows the app to detect network connectivity changes so it can respond to drops in the underlying connection. |
| `FOREGROUND_SERVICE` | Keeps the VPN service running in the foreground so Android does not terminate it while you are connected. |
| `FOREGROUND_SERVICE_SPECIAL_USE` | Required on Android 14+ for VPN services that use the `specialUse` foreground service type. |
| `POST_NOTIFICATIONS` | Allows the app to show status notifications (connected, reconnecting, errors) in the notification shade. |

## Granting VPN permission

The first time you toggle the connect switch, Android displays a system dialog asking you to authorize the app to set up a VPN connection. This is a standard Android security prompt, not specific to Open SSTP Client.

<Steps>
  <Step title="Tap the connect switch in the Home tab">
    The system VPN permission dialog appears automatically on first use.
  </Step>
  <Step title="Review the dialog and tap OK">
    Android shows which app is requesting VPN access. Tap **OK** to grant permission. You will not be prompted again unless the app is reinstalled.
  </Step>
</Steps>

<Note>
  On **Android 13 and later**, the system also prompts you to allow the app to send notifications when it first needs to display a status or error notification. Tap **Allow** to receive connection status updates in the notification shade.
</Note>
